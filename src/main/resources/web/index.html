Plugins Minecraft

Comment ca marche ?

Upload d’un plugin :

Cliquez sur Upload sans sélectionner de plugin existant pour ajouter un nouveau fichier .jar. Si un plugin avec un nom similaire existe déjà, le système pourra automatiquement le renommer si nécessaire.

Mise à jour d’un plugin :

Sélectionnez un plugin déjà installé, puis utilisez Upload pour remplacer ou mettre à jour le fichier existant. Le système mettra à jour le plugin sélectionné, même si le nom du nouveau fichier est différent.

Suppression d'un plugin :

Cliquez sur Delete pour supprimer définitivement le plugin sélectionné de la liste.
